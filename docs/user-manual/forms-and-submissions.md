## Find a form

Use the dashboard or the forms area to browse available forms. Before starting, review:

- the form description
- instructions
- deadline
- whether edits are allowed after submission

---

## Complete form questions

FORMNA forms may include:

- short text
- long text
- email fields
- numbers
- dates
- dropdowns
- checkboxes
- radio buttons
- file uploads

Tips:

- answer required questions marked by the system
- read help text where available
- expect some questions to appear only when relevant based on prior answers

---

## Upload files

When a form requests documents:

1. choose the file upload field
2. select one or more files if allowed
3. wait for upload confirmation
4. verify the uploaded filename is correct

Always check file size and allowed file type guidance shown in the form.

---

## Save drafts

FORMNA supports draft-saving so you can continue later.

Best practice:

- confirm the form shows a saved state before leaving
- return through **My Submissions** or the dashboard
- delete drafts only if you are sure you no longer need them

---

## Submit and track

Before you submit:

1. review every answer
2. verify uploaded files
3. confirm all required questions are complete

After submission, you can usually track statuses such as:

- draft
- submitted
- in review
- clarification requested
- approved
- rejected
