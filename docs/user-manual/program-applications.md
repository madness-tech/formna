## What a program is

A program combines multiple forms into a single application process. Examples include scholarship applications, grant programs, hiring workflows, and admissions packages.

---

## Start an application

To begin:

1. open the programs area
2. choose a program
3. review requirements and instructions
4. start the application

Pay close attention to required forms and the final deadline.

---

## Complete required forms

Programs often show each required item with a progress state such as:

- not started
- in progress
- completed

You may need to submit several forms before the overall program application can be submitted.

---

## Attach existing submissions

If a program allows reuse of an already submitted form, you may be able to attach a previous submission instead of filling it out again.

This is useful when the same form supports multiple programs.

---

## Submit and track your application

Once all required forms are complete:

1. review the attached submissions
2. submit the program application
3. monitor status in **My Applications**

Program statuses commonly include:

- draft
- submitted
- in review
- approved
- rejected

Some programs also display the current review stage.
