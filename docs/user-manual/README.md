# User Manual

End-user documentation for FORMNA applicants and participants.

This section explains how to create an account, log in, complete forms, apply to programs, respond to clarification requests, and manage your account.

---

## Who this section is for

- applicants
- participants
- external users invited to submit information
- general end users of the platform

## What you can do in FORMNA

- create and verify your account
- complete online forms
- save drafts and return later
- upload supporting documents
- apply to multi-form programs
- track submission and application status
- respond to administrator clarification requests
- manage language, password, and notification preferences
