## What programs are

Programs combine multiple forms into a single application workflow. They are well suited for grants, scholarships, jobs, admissions, and other multi-document processes.

Programs typically define:

- required forms
- optional forms
- application instructions
- deadlines
- review stages
- reviewer assignments

---

## Creating a program

1. open **Programs**
2. choose **Create Program**
3. enter the program name, description, instructions, and deadline
4. save the program as draft

---

## Adding forms

Attach forms to the program and mark each as:

- **required**: must be completed before submission
- **optional**: available but not mandatory

Programs can reuse forms already created elsewhere in the platform.

---

## Review stages

Programs can support staged decision-making.

Typical process:

1. define stage names and descriptions
2. assign reviewers to each stage
3. publish the program
4. applications move through the stages sequentially

Common examples:

- initial screening
- committee review
- final approval

---

## Managing applications

Administrators can typically:

- view applications by status and stage
- inspect all attached form submissions
- assign or reassign reviewers
- approve or reject at the stage level
- monitor progress and reporting

Programs can also be closed to new submissions while allowing existing applications to finish the review lifecycle.

---

## Operational guidance

- publish programs only after attached forms are validated
- align deadlines across all required forms
- define stage responsibilities clearly
- use reviewer notes consistently
- communicate timelines to applicants wherever possible
