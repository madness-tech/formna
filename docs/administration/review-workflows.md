## Review queue

Reviewers and administrators use the review queue to find assigned items awaiting action.

Typical filters include:

- form or program
- status
- stage
- assignment

---

## Reviewing submissions

During review, staff can usually:

- read answers inline
- inspect uploaded files
- review prior clarifications
- generate AI summaries if enabled
- approve, reject, or request clarification

---

## Program stage decisions

For multi-stage programs, reviewers evaluate the current stage only. Outcomes generally include:

- approve and move to the next stage
- reject and stop the application
- request clarification if more information is needed

---

## Clarification requests

Clarifications are used when a response is incomplete, unclear, or requires correction.

Good clarification requests are:

- specific
- professional
- consolidated into a single request where possible
- clearly linked to the affected question or document

Statuses generally include:

- open
- responded
- resolved
- rejected
- cancelled

---

## Best practices

- use consistent internal review criteria
- keep reviewer notes professional and factual
- request clarifications only when they materially help a fair decision
- avoid repeated low-value back-and-forth with applicants
- always verify AI-generated summaries against actual submission data
